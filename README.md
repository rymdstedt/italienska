# Impara l'italiano

En italienskakurs på svenska, från nybörjare (A1) till nästan flytande (B2), med skriftliga och muntliga övningar.

**Öppna kursen:** https://rymdstedt.github.io/italienska/

## Röst

Alla fraser är inlästa med rösten **Serena** från [Piper](https://github.com/rhasspy/piper)
([modell](https://huggingface.co/rhasspy/piper-voices/tree/main/it/it_IT/serena/high)), tränad på
datasetet [serena-synthetic-it-27h](https://huggingface.co/datasets/committa/serena-synthetic-it-27h),
licensierat under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Om du ändrar eller lägger till fraser i `index.html`, spela in de nya med skripten i `tools/`
(se instruktionerna i `tools/make_audio.py`). Fraser som saknar inspelning läses upp med enhetens egen röst.
